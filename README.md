# MAX чат — тестовое задание (React + GREEN-API)

Пользовательский интерфейс для отправки и получения текстовых сообщений в мессенджере MAX
через сервис [GREEN-API](https://green-api.com/max). Внешний вид повторяет прототип
[web.max.ru](https://web.max.ru/).

## Локальный запуск

Требования: Node.js 18+ и npm.

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:5173

Сборка production-версии:

```bash
npm run build      # проверка типов + сборка в dist/
npm run preview    # локальный просмотр сборки
```

## Подготовка GREEN-API

1. Зарегистрируйтесь в [личном кабинете GREEN-API](https://console.green-api.com)
   (бесплатного тарифа «Разработчик» достаточно).
2. Создайте инстанс для мессенджера MAX (доступно для страны "Россия").
3. Авторизуйте инстанс: отсканируйте QR-код из личного кабинета приложением MAX
   (статус инстанса должен стать `authorized`).
4. Скопируйте `idInstance`, `apiTokenInstance` и `apiUrl` (вида `https://XXXX.api.green-api.com`)
   со страницы инстанса.

> `idInstance` и `apiTokenInstance` — это секретные учетные данные: любой, кто ими владеет,
> может отправлять сообщения от имени привязанного аккаунта. Не публикуйте их в репозитории.
> Приложение хранит их только в `localStorage` вашего браузера и обращается напрямую к API
> GREEN-API, промежуточных серверов нет.

## Использование

1. На экране входа введите `idInstance`, `apiTokenInstance` и `apiUrl` из личного кабинета.
2. Введите номер телефона получателя и нажмите «Создать» — приложение проверит наличие
   аккаунта MAX на этом номере и откроет чат.
3. Пишите и отправляйте текстовые сообщения — они приходят получателю в MAX.
4. Ответы получателя подтягиваются в чат автоматически.

При первом входе приложение автоматически настраивает инстанс для получения уведомлений
по технологии HTTP API (`setSettings`: пустой `webhookUrl`, включены входящие/исходящие
вебхуки).

## Используемые методы API

| Метод | Назначение |
| --- | --- |
| `GET getStateInstance` | Проверка учетных данных при входе |
| `POST setSettings` | Включение получения уведомлений по HTTP API |
| `POST checkAccount` | Получение `chatId` по номеру телефона |
| `POST sendMessage` | Отправка текстового сообщения |
| `GET receiveNotification` | Получение входящих уведомлений (long polling) |
| `DELETE deleteNotification` | Подтверждение обработки уведомления |

Дополнительно обрабатываются уведомления `outgoingMessageStatus`
(галочки доставки/прочтения) и `outgoingMessageReceived` (сообщения, отправленные
с телефона, отображаются в чате).

## Технологии

- React 18 + TypeScript (strict)
- Vite
- Без UI-библиотек и стейт-менеджеров — только CSS и React API

## Структура проекта

```
src/
  api/greenApi.ts        — клиент GREEN-API (fetch-обертки над методами)
  components/
    LoginScreen.tsx      — экран ввода учетных данных
    Sidebar.tsx          — список чатов, создание чата по номеру
    ChatWindow.tsx       — окно переписки, поле ввода, статусы сообщений
  utils/phone.ts         — нормализация и форматирование номеров
  utils/errors.ts        — извлечение текста ошибок
  types.ts               — типы: Credentials, Chat, Message, уведомления API
  App.tsx                — состояние приложения, цикл получения уведомлений
```

## Деплой

Сборка — статический SPA-бандл (`dist/`), подходит для любого статического хостинга:

- **GitHub Pages**: `npm run build` и выложить содержимое `dist/` в ветку `gh-pages`
  (свойство `base: './'` в `vite.config.ts` уже настроено под подкаталог).
- **Vercel / Netlify**: указать команду сборки `npm run build` и каталог `dist`.
